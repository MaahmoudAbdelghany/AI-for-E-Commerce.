# Requirements: Feature 1.3 — Pluggable Catalog Layer & TTL Caching

> Decisions and behaviours, not implementation micro-details. Every requirement must be testable and map to at least one check in `validation.md`.

## 1. Functional Requirements

| ID | Requirement | Validated by (`validation.md` check) |
|:---|:---|:---|
| **R1** | The system must define pure abstract `typing.Protocol` interfaces in `commerce_ai.domain.ports`: `CatalogProvider` (`async def search_offers(self, intent: SearchIntent) -> CatalogSearchResult`) and `CacheStore` (`async def get(self, key: str) -> str | None`, `async def set(self, key: str, value: str, ttl_seconds: int) -> None`, `async def delete(self, key: str) -> None`). | `T1.1`, `T5.3` |
| **R2** | `InMemoryTTLCache` (`adapters/cache/memory.py`) must implement `CacheStore` in-process using monotonic clock expiration and a bounded `collections.OrderedDict` (`max_entries: int = 1024`, validating `max_entries > 0`) so missing or expired keys return `None` (and are pruned), capacity-full `set()` calls prune expired entries and evict the least-recently-used entry, valid keys within TTL return stored string payloads (updating recency), and `delete()` removes keys idempotently without error on missing keys. | `T1.2`, `T3.7` |
| **R3** | `RedisCacheStore` (`adapters/cache/redis_store.py`) must implement async `CacheStore` over `redis.asyncio` (accepting either an injected async Redis client for offline `fakeredis` verification or a `redis_url`), storing UTF-8 strings with `EX` TTL expiration and wrapping Redis transport/operational failures in `CacheStoreError` without exposing URL credentials. | `T1.3`, `T3.6` |
| **R4** | The cache factory (`adapters/cache/factory.py`) must return `InMemoryTTLCache` when `AppSettings.redis_url` is unset or empty, return `RedisCacheStore` when `redis_url` is configured and reachable, and automatically fall back to `InMemoryTTLCache` with a sanitized warning when `REDIS_URL` is unreachable (`P1`, `INV-08`). | `T1.4`, `T2.3`, `T3.8` |
| **R5** | Versioned JSON seed catalogs (`eg.json`, `sa.json`, `ae.json`) under `backend/src/commerce_ai/adapters/catalog/seeds/` must span at least 5 product categories across both `noon` and `amazon` in each country (`EGP`/`SAR`/`AED`), use bilingual Arabic/English titles and search tags, satisfy `ProductOffer` & `P2` regional URL validation, and include deliberate test traps (bilingual accessories, `5.0`-star `1`-review items, unrated `rating=None`/`review_count=0` items, and `4x` overpriced scalper outliers) (`P6`). | `T1.5`, `T1.6` |
| **R6** | `SeedCatalogProvider` (`adapters/catalog/seed_provider.py`) must implement `CatalogProvider`, match Arabic and English `SearchIntent.query` tokens against regional seed titles/brands/tags, filter by `intent.country` and `intent.store` (`noon`, `amazon`, `both`), preserve matching trap candidates for downstream ranking, and return `CatalogSearchResult(..., source_mode=CatalogSourceMode.SEED, cache_hit=False)`. | `T1.5`, `T1.6`, `T3.9` |
| **R7** | `SerperShoppingProvider` (`adapters/catalog/serper_provider.py`) must implement `CatalogProvider` by issuing strictly **1** async `POST https://google.serper.dev/shopping` call per `search_offers(intent)` invocation with `num=40`, `gl` mapped via `MARKET_REGISTRY` (`eg`/`sa`/`ae`), `hl` set to `intent.language` (`ar`/`en`), a store hint appended when `intent.store` is `"noon"` or `"amazon"`, `X-API-KEY` header from `AppSettings.serper_api_key`, and timeout `AppSettings.serper_timeout_seconds` (`2.0s`), returning `CatalogSearchResult(..., source_mode=CatalogSourceMode.LIVE, cache_hit=False)` (`P5`). | `T1.7`, `T1.8`, `T2.2` |
| **R8** | `SerperShoppingProvider` must deterministically parse Serper `"shopping"` items into `ProductOffer` objects using `MARKET_REGISTRY[intent.country].currency` and quantized `Decimal` prices, enforcing `P2` regional store & Google Shopping attribution directly via Feature 1.1's `commerce_ai.config.markets.validate_regional_offer_url(url, country=intent.country, store=..., merchant_attribution=...)` and `ProductOffer.model_validate(..., context={"merchant_attribution": ...})`. Only `https://` official regional Noon/Amazon URLs (`amazon.eg`, `noon.com/egypt*`, `amazon.sa`, `noon.com/saudi*`, `amazon.ae`, `noon.com/uae*`) or verified Google Shopping HTTPS links (`google.com/shopping/...`, `google.{com.eg,com.sa,ae}`) with explicit regional `Noon`/`Amazon` merchant attribution matching `intent.store` may pass; invalid, non-HTTPS, cross-country (`amazon.com`), unattributed, or third-party seller entries must be skipped without fabricating fields or crashing valid items (`P2`, `INV-05`). | `T1.8`, `T1.9`, `T3.4` |
| **R9** | `SerperShoppingProvider` must raise typed `CatalogProviderError(provider="serper", retriable=..., reason=...)` on request timeout (`retriable=True`), transport failures (`retriable=True`), HTTP `429`/`5xx` (`retriable=True`), HTTP `400`/`401`/`403`/`404` (`retriable=False`), or malformed/non-JSON/non-list `"shopping"` responses (`retriable=False`), and must never silently serve `SeedCatalogProvider` offers as live results (`P5`, `P6`, `INV-08`). | `T3.1`, `T3.2`, `T3.3` |
| **R10** | `CachedCatalogProvider` (`adapters/catalog/cached_provider.py`) must wrap a `CatalogProvider` and a `CacheStore`, read and write serialized `CatalogSearchResult` payloads under `intent.normalized_cache_key()`, return `CatalogSearchResult(..., cache_hit=True)` on cache hits without calling the wrapped provider, and persist valid results on cache misses with configured TTL returning `cache_hit=False`. | `T2.1`, `T2.2` |
| **R11** | `CachedCatalogProvider` must never cache `CatalogProviderError` failures (always propagating provider errors cleanly), and must degrade gracefully to calling the wrapped `CatalogProvider` and returning its valid `CatalogSearchResult` whenever `CacheStore.get()`, `CacheStore.set()`, or cached JSON deserialization fails (`INV-08`). | `T3.5` |
| **R12** | The catalog factory (`adapters/catalog/factory.py`) must honor `AppSettings.catalog_mode` (`"auto"` \| `"seed"` \| `"serper"`, default `"auto"`): `"seed"` creates `SeedCatalogProvider`; `"auto"` creates `SeedCatalogProvider` when `serper_api_key` is empty/unset and `SerperShoppingProvider` when configured; `"serper"` creates `SerperShoppingProvider` when configured and raises `CatalogProviderError(provider="serper", retriable=False, ...)` immediately when `serper_api_key` is empty/unset; and optionally wraps the provider in `CachedCatalogProvider` (`P6`). | `T1.10`, `T2.3`, `T3.10` |

## 2. Non-Functional Requirements

| ID | Requirement | Validated by (`validation.md` check) |
|:---|:---|:---|
| **NFR1** | **Unit Cost Ceiling (`spec/mission.md` §4, `P5`)**: `SerperShoppingProvider` must perform at most 1 external HTTP request per uncached query (`~$0.001 <= $0.002` budget) and `CachedCatalogProvider` must perform 0 external HTTP requests on cache hits. | `T1.7`, `T2.2` |
| **NFR2** | **Secret Safety & Link Security (`INV-01`, `INV-09`)**: Source code, seed datasets, logs, and raised exceptions (`CatalogProviderError`, `CacheStoreError`) must never hardcode or leak `SERPER_API_KEY`, `REDIS_URL` passwords, or PII, and all emitted product URLs must enforce `https://`. | `T1.9`, `T3.3`, `T3.6` |
| **NFR3** | **Hexagonal Boundary Integrity (`INV-02`)**: `commerce_ai.domain.ports` must contain zero imports from `adapters/`, `httpx`, `redis`, or other infrastructure libraries; all vendor I/O must reside exclusively inside `adapters/`. | `T1.1`, `T5.3` |
| **NFR4** | **100% Offline Deterministic Verification (`INV-07`)**: All unit and integration tests must run cleanly offline in `< 30 s` without Docker, external Redis, or live API keys using `InMemoryTTLCache`, `fakeredis`, `SeedCatalogProvider`, and `httpx.MockTransport` (any optional live test is tagged `@pytest.mark.live` and excluded from default offline runs). | `T1.3`, `T1.7`, `T2.2`, `T4.1` |
| **NFR5** | **Sanctioned Data Acquisition (`INV-06`)**: Live search must rely solely on the commercial Serper Shopping REST API over `httpx` with zero headless browser scraping or anti-bot/CAPTCHA circumvention. | `T1.7`, `T5.1` |
| **NFR6** | **Static Quality, Formatting & Type Safety**: All created modules and tests must pass `ruff check .`, `ruff format --check .`, `mypy src`, and full `pytest` regression checks without warnings or errors. | `T4.1`, `T5.1`, `T5.2`, `T5.3`, `T5.4` |

## 3. Constraints (must NOT do / change)

- **C1 (`INV-01`)**: Must NOT hardcode any API keys, credentials, or live `.env` secrets in code, seed JSON files, logs, or test assertions.
- **C2 (`INV-02`)**: Must NOT import vendor SDKs (`httpx`, `redis`, `fakeredis`) inside `backend/src/commerce_ai/domain/ports.py`.
- **C3 (`INV-05`, `P6`)**: Must NOT fabricate missing prices, ratings, review counts, or URLs when parsing Serper results, and must NOT silently fall back to `SeedCatalogProvider` when live `SerperShoppingProvider` fails or times out.
- **C4 (`INV-06`)**: Must NOT introduce Playwright, Selenium, HTML storefront scrapers, or anti-bot/CAPTCHA bypass logic.
- **C5 (`P7`)**: Must NOT create or modify `backend/pyproject.toml`, `backend/src/commerce_ai/domain/__init__.py`, package `__init__.py` scaffolds created by Feature 1.1, `backend/src/commerce_ai/config/`, `backend/src/commerce_ai/domain/models.py`, `backend/src/commerce_ai/domain/errors.py`, or `backend/src/commerce_ai/domain/ranking.py` (owned by Features 1.1 and 1.2).

## 4. Dependencies & Assumptions

- **Depends on**:
  - **Feature 1.1 (must be implemented first)**: `backend/pyproject.toml` dependencies (`pydantic`, `pydantic-settings`, `httpx`, `redis`, `pytest`, `pytest-asyncio`, `fakeredis`, `ruff`, `mypy`) and registered `@pytest.mark.live` marker; package `__init__.py` scaffolds; `commerce_ai.domain.models` (`CountryCode`, `CurrencyCode`, `StoreId`, `StoreFilter`, `CatalogSourceMode`, `ProductOffer` with `context={"merchant_attribution": ...}` support, `SearchIntent` with `normalized_cache_key()`, `CatalogSearchResult`); `commerce_ai.domain.errors` (`DomainError`, `OfferValidationError`, `CatalogProviderError`, `CacheStoreError`); and `commerce_ai.config` (`AppSettings`, `MarketConfig`, `MARKET_REGISTRY`, `validate_regional_offer_url`).
  - **Environment variable names only (`INV-01`)**: `SERPER_API_KEY`, `REDIS_URL`, `CATALOG_MODE`, `CACHE_TTL_SECONDS`, `SERPER_TIMEOUT_SECONDS` (all optional locally; defaults run offline).
- **Assumptions**:
  - Feature 1.1 exports and validates all `P2` regional store URL rules inside `ProductOffer` (and `MARKET_REGISTRY` supplies `serper_gl`, `currency`, and allowed regional domain prefixes for `EG`, `SA`, `AE`) so `SerperShoppingProvider` and `SeedCatalogProvider` share the canonical `P2` contract without duplicating conflicting validation rules.
  - `httpx` and `fakeredis` are available in the `uv`-managed environment created by Feature 1.1 (`uv sync --directory backend --all-extras --dev`) for 100% offline test execution.
