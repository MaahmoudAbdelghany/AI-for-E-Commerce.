## 2. Non-Functional Requirements

| ID | Requirement | Validated by (`validation.md` check) |
| :--- | :--- | :--- |
| **NFR1** | **100% Offline Determinism & Build Reliability (`INV-07`, `P2`, `P8`)**: `npm --prefix frontend test` (`vitest run`) and `npm --prefix frontend run build` (`next build`) MUST pass completely offline with zero live backend or internet requests (mocked `fetch`, zero `next/font/google`), and all existing backend tests (`pytest -v`) MUST remain green. | `T4.1`, `T4.2`, `T5.3` |
| **NFR2** | **Secret Hygiene, Safe Proxy & Sanitized Outbound Links (`INV-01`, `INV-08`, `INV-09`)**: `NEXT_PUBLIC_*` bundles, client storage, and `503 backend_unreachable` proxy responses MUST NEVER expose `BACKEND_API_URL`, API keys, or stack traces, and `sanitizeHttpsUrl` MUST block `http:`, `javascript:`, credentials, backslashes, and whitespace/control characters. | `T1.3`, `T2.2`, `T3.3`, `T3.4`, `T3.5` |
| **NFR3** | **Strict Grounding & Decimal Precision Preservation (`INV-03`, `INV-05`)**: TypeScript contracts, `api.ts`, proxy routes, `storage.ts`, and `formatExactPrice` MUST preserve backend `DecimalString` prices, `RankedOffer` ordering, and upstream JSON error/response envelopes verbatim without float drift or client-side re-sorting. | `T1.1`, `T1.3`, `T2.1`, `T3.5` |
| **NFR4** | **Static Type Safety, Non-Interactive Linting & Partition Integrity (`P7`, `spec/sdd-profile.md`)**: `eslint src tests` and `tsc --noEmit` (`strict: true`, `noUncheckedIndexedAccess: true`) MUST pass cleanly with zero interactive prompts, and Feature 3.1 MUST NOT touch `backend/**`, `spec/sdd-profile.md` Sensitive Areas, or Feature 3.2 / `PI.1` reserved paths. | `T4.2`, `T5.1`, `T5.2`, `T5.4` |
| **NFR5** | **Accessibility, RTL/LTR Fidelity & Responsive Layout (`P4`, `spec/mission.md` §7)**: Every selector, button, input, and badge MUST provide semantic labels (`<label>`, `role="radiogroup"`, `aria-invalid`, `role="status"`/`role="alert"`), instant `dir="rtl"` (`lang="ar"`) <-> `dir="ltr"` (`lang="en"`) switching without reload, and responsive layout across `1280px` desktop and `375px` mobile viewports with zero horizontal overflow. | `T2.4`, `T6.1`, `T6.2` |

## 3. Constraints (must NOT do / change)

- **C1 (`INV-07`)**: Must NOT import `next/font/google` or depend on external internet font/CDN calls during `next build` or Vitest execution.
- **C2 (`INV-01`, `INV-08`)**: Must NOT hardcode secrets, put server-side secrets in `NEXT_PUBLIC_*` environment variables, or leak `BACKEND_API_URL` or raw error stack traces in Route Handler `503` responses.
- **C3 (`INV-03`, `INV-05`)**: Must NOT convert `ProductOffer.price` or `SearchIntent.max_budget` `DecimalString` payloads through imprecise floating-point math, nor re-sort or fabricate offers client-side.
- **C4 (`P7`)**: Must NOT create or modify `frontend/src/components/workspace/**`, `frontend/tests/unit/offer-card-and-banners.test.tsx`, `frontend/tests/integration/shopping-workspace.test.tsx`, `frontend/tests/integration/phase3-e2e.test.tsx`, or any file inside `backend/**`.
- **C5 (`spec/sdd-profile.md`)**: Must NOT touch Sensitive Areas (`infra/aws/**`, `.github/workflows/**`, `backend/src/commerce_ai/config/security*`, `backend/migrations/**`).

## 4. Dependencies & Assumptions

- **Depends on**:
  - **Phase 2 Backend (`Feature 2.3`, committed on `main`)**: FastAPI routes `POST /api/v1/chat`, `POST /api/v1/search`, `GET /api/v1/markets`, `GET /health`, and schemas in `backend/src/commerce_ai/api/schemas.py`.
  - **Local Toolchain (`P2`)**: `Node.js LTS` + `npm` installed in the Phase 3 environment (`OpenJS.NodeJS.LTS`), plus `uv` / Python `3.11+` for backend regression checks and Tier 7 local full-stack smoke.
  - **Environment variable names only (`INV-01`)**: `BACKEND_API_URL` (server-side runtime Route Handler target, defaulting to `http://127.0.0.1:8000`) and optional `NEXT_PUBLIC_API_BASE_URL` (browser override, unset/empty by default).
- **Assumptions**:
  - `Next.js 15` (`^15`) App Router supports `export const dynamic = "force-dynamic"` and async `context.params` (`Promise<{ path?: string[] }>`) in Route Handlers cleanly with React 19 and Vitest `jsdom`.
  - Feature 3.2 will mount `<ShoppingWorkspace />` inside `<AppShell>` in `frontend/src/app/page.tsx` while consuming `src/lib/*` and `src/context/ShopSessionContext.tsx` read-only (`P7`).
