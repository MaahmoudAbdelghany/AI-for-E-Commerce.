# Requirements: Feature 2.1 — LLM Routing, Guardrails & Bilingual Intent Extraction

> Decisions and behaviours, not implementation micro-details. Every requirement is testable and maps bidirectionally to checks in [validation.md](validation.md).

## 2. Non-Functional Requirements

| ID | Requirement | Validated by (`validation.md`) |
|:---|:---|:---|
| NFR1 | **Secret & PII Protection (`INV-01`, `INV-09`)**: `AppSettings` MUST mask secrets (`gemini_api_key`, `groq_api_key`, `openai_api_key`, `serper_api_key`, `redis_url`, `database_url`) across `repr()`, `str()`, `model_dump()`, `model_dump_json()`, and `safe_summary()`; `GeminiLLMClient` MUST send keys via `x-goog-api-key` header (never URL query params); LLM adapters MUST redact keys in `LLMProviderError` and logs; `check_input_guardrails` MUST block payment/PII inputs at `0` tokens without echoing sensitive payloads. | T1.2, T1.6, T3.1, T3.5, T3.8 |
| NFR2 | **Strict Hexagonal Boundary (`INV-02`)**: `commerce_ai.config`, `commerce_ai.domain`, and Feature 2.1 `commerce_ai.agent` (`guardrails.py`, `intent.py`) MUST import zero adapter, HTTP, database, or vendor LLM SDK packages (`httpx`, `redis`, `serper`, `langfuse`, `boto3`, `sqlalchemy`, `fastapi`, `litellm`, `openai`, `groq`, `google`). | T1.15, T5.4 |
| NFR3 | **100% Offline Determinism & Bounded Cost (`INV-04`, `INV-07`)**: The complete backend `pytest` suite MUST pass 100% offline in `< 30 s` without external API keys; intent parsing MUST stay bounded to at most 1 logical LLM step (`max_tokens <= 350`), failover at most once, and catalog caching MUST avoid duplicate provider requests across concurrent or refined follow-up searches. | T1.8, T1.12, T2.1, T2.2, T4.1 |
| NFR4 | **Toolchain, Lockfile & Static Quality**: `uv lock --directory backend --check`, `uv run --directory backend ruff check .`, `uv run --directory backend ruff format --check .`, and `uv run --directory backend mypy src` MUST all pass with zero warnings or errors. | T5.1, T5.2, T5.3, T5.4 |

## 3. Constraints

- **C1**: Must uphold `spec/tech.md` invariants `INV-01`, `INV-02`, `INV-04`, `INV-05`, `INV-07`, `INV-08`, and `INV-09`.
- **C2 (`P7`)**: Disjoint File Ownership — Feature 2.1 MUST NOT modify `domain/ranking.py`, `adapters/catalog/seed_provider.py`, `adapters/catalog/serper_provider.py`, `adapters/cache/*`, or create Feature 2.2/2.3 modules (`adapters/session/{memory,sqlalchemy_repo,factory}.py`, `agent/{prompts,templates,graph}.py`, `main.py`, `api/{schemas,dependencies,middleware,errors,routes}.py`, `tests/integration/test_phase2_e2e.py`). Feature 2.1 MUST NOT touch `spec/sdd-profile.md` Sensitive Areas (`infra/aws/**`, `.github/workflows/**`, `config/security*`, `migrations/**`) or `frontend/`.
- **C3 (`P2`)**: Must NOT introduce `litellm` or heavy vendor LLM SDK dependencies (`google-genai`, `openai`, `groq`, `boto3`); all LLM network I/O stays inside `commerce_ai.adapters.llm` via async `httpx`.
- **C4**: Must never hardcode credentials or commit `.env` files (`INV-01`).

## 4. Dependencies & Assumptions

- **Depends on**: Phase 1 (`Feature 1.1`, `Feature 1.2`, `Feature 1.3` — committed on `main`). Downstream consumers: `Feature 2.2` (`agent/graph.py`, `adapters/session/`) and `Feature 2.3` (`main.py`, `api/`).
- **Environment variables (names only)**: `APP_ENV`, `LOG_LEVEL`, `GEMINI_API_KEY`, `GROQ_API_KEY`, `OPENAI_API_KEY`, `LLM_MODE`, `EXPLAIN_MODE`, `LLM_PRIMARY_MODEL`, `LLM_FALLBACK_MODEL`, `LLM_TIMEOUT_SECONDS`, `GUARDRAIL_MAX_CHARS`, `DATABASE_URL`, `SESSION_TTL_SECONDS`, `SESSION_MAX_TURNS`, `CORS_ALLOWED_ORIGINS`, `RATE_LIMIT_RPM`, plus existing Phase 1 variables (`SERPER_API_KEY`, `REDIS_URL`, `CATALOG_MODE`, `CACHE_TTL_SECONDS`, `SERPER_TIMEOUT_SECONDS`).
- **Assumptions**:
  - `uv` (`>= 0.13`) and Python `3.11+` are available and can resolve the new Phase 2 dependencies once into `backend/uv.lock` during Group 1 (`uv sync --directory backend --all-extras --dev`), after which all test and static checks run 100% offline.
  - Existing `backend/.env.example` remains compatible out of the box with `AppSettings` (which ignores unknown Phase 4 variables and handles inline `#` comments, empty secrets, and unquoted `CORS_ALLOWED_ORIGINS`).
