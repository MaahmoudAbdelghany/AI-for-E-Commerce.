# Requirements: Feature 2.3 — Versioned FastAPI Service, Middleware & API Contracts

> Decisions and behaviours, not implementation micro-details. Every requirement is testable and maps bidirectionally to checks in [validation.md](validation.md).

## 2. Non-Functional Requirements

| ID | Requirement | Validated by (`validation.md` check) |
| :--- | :--- | :--- |
| **NFR1** | **Repeat-Response Performance Budget (`spec/mission.md` §4 & §6)**: Offline cached repeat `POST /api/v1/search` requests hitting `InMemoryTTLCache` MUST complete in `<= 300 ms`. | `T2.2` |
| **NFR2** | **Secret, Stack-Trace & PII Hygiene (`INV-01`, `INV-09`)**: `HealthResponse`, `ErrorResponse`, server error logs, and `POST /api/v1/chat` guardrail refusal responses MUST expose zero API keys, database/Redis passwords, raw connection URLs, stack traces, or payment/sensitive PII payloads. | `T1.4`, `T1.5`, `T3.1`, `T3.4`, `T3.5` |
| **NFR3** | **Hexagonal Boundaries, Bounded Cost, Grounding & Offline Determinism (`INV-02`, `INV-04`, `INV-05`, `INV-07`)**: `commerce_ai.api` and `commerce_ai.main` MUST NOT bypass domain ports/factories with direct vendor DB/LLM/Serper SDK requests; `POST /api/v1/search` executes `0` LLM calls; `POST /api/v1/chat` preserves `<= 2` LLM calls and unmodified `ProductOffer` grounding; and all unit/integration tests pass 100% offline in `< 30 s`. | `T1.7`, `T2.2`, `T2.3`, `T4.1` |
| **NFR4** | **Code Quality, Static Typing & OpenAPI 3.1 Contract Readiness (`spec/sdd-profile.md`)**: All created modules and tests MUST pass `ruff check .`, `ruff format --check .`, and `mypy src` cleanly, and `/openapi.json` MUST expose valid OpenAPI 3.1 paths and typed component schemas for Phase 3 frontend codegen. | `T2.4`, `T5.1`, `T5.2`, `T5.3` |

## 3. Constraints (must NOT do / change)

- **C1 (`INV-01`, `INV-09`)**: Must NOT hardcode secrets, return raw `REDIS_URL`/`DATABASE_URL` strings in `/health` or `ErrorResponse`, return Python stack traces in `500` responses, or add login/payment/checkout endpoints.
- **C2 (`INV-02`)**: Must NOT embed direct `serper`, `redis`, `sqlalchemy`, or LLM HTTP client logic inside `api/routes.py`; routes MUST delegate strictly through injected `CatalogProvider`, `ShoppingAssistantWorkflow`, `rank_top_offers`, and `MARKET_REGISTRY`.
- **C3 (`INV-04`, `INV-05`)**: Must NOT invoke `LLMClient` inside `POST /api/v1/search` and must NOT modify `ProductOffer` prices, ratings, review counts, or URLs returned by `rank_top_offers` / `ShoppingAssistantWorkflow`.
- **C4 (`P7`)**: Must NOT modify `backend/pyproject.toml`, `backend/uv.lock`, any `__init__.py` scaffold (`commerce_ai/api/__init__.py`, etc.), `config/`, `domain/`, `adapters/`, `agent/`, or `backend/tests/integration/test_phase2_e2e.py`.
- **C5 (`spec/sdd-profile.md`)**: Must NOT touch Sensitive Areas (`infra/aws/**`, `.github/workflows/**`, `config/security*`, `migrations/**`).

## 4. Dependencies & Assumptions

- **Depends on**:
  - **Feature 2.1 (must be implemented first)**: `backend/pyproject.toml` (`fastapi`, `uvicorn[standard]`, `langgraph`, `sqlalchemy[asyncio]`, `aiosqlite`, `asyncpg`), `commerce_ai/api/__init__.py`, updated `AppSettings` (`app_env`, `llm_mode`, `guardrail_max_chars`, `cors_allowed_origins`, `rate_limit_rpm`, `session_ttl_seconds`, `session_max_turns`, `redact_url_password`), updated `domain/models.py` (`TurnAction`, `TurnStatus`, `TurnTelemetry`, `ChatTurnResult`), updated `domain/errors.py` (`LLMProviderError`, `SessionStoreError`), and `adapters/llm/factory.py` (`create_llm_client`).
  - **Feature 2.2 (must be implemented before or alongside)**: `adapters/session/` (`create_session_repository`, `ResilientSessionRepository` exposing `initialize()`, `close()`, `backend_name`, `is_degraded`, plus `InMemorySessionStore` and `SQLAlchemySessionRepository`) and `agent/graph.py` (`ShoppingAssistantWorkflow`).
  - **Phase 1 (done)**: `MARKET_REGISTRY`, `rank_top_offers`, `create_cache_store`, `create_catalog_provider`, `SeedCatalogProvider`, `InMemoryTTLCache`.
  - **Environment variable names only (`INV-01`)**: `APP_ENV`, `LOG_LEVEL`, `CORS_ALLOWED_ORIGINS`, `RATE_LIMIT_RPM`, `CATALOG_MODE`, `LLM_MODE`, `EXPLAIN_MODE`, `SERPER_API_KEY`, `GEMINI_API_KEY`, `GROQ_API_KEY`, `OPENAI_API_KEY`, `REDIS_URL`, `DATABASE_URL` (all optional in offline tests).
- **Assumptions**:
  - `httpx.ASGITransport` is available from the existing `httpx>=0.27` dependency declared in `backend/pyproject.toml`, enabling 100% offline ASGI HTTP testing without starting a live TCP socket.
  - `FastAPI>=0.115` generates OpenAPI 3.1 schemas natively from Pydantic v2 models without additional codegen plugins.
