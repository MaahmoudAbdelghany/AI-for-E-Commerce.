# Requirements: Feature 1.1 — Backend Scaffold, Config & Regional Marketplace Domain Models

> Decisions and behaviours, not implementation micro-details. Every requirement is testable and maps bidirectionally to checks in [validation.md](validation.md).

## 2. Non-Functional Requirements

| ID | Requirement | Validated by (`validation.md`) |
|:---|:---|:---|
| NFR1 | **Secret & PII Safety (`INV-01`, `INV-09`)**: `AppSettings` MUST never expose `serper_api_key` or credentials embedded in `redis_url` via `repr()`, `str()`, or diagnostic summaries; `backend/.env.example` MUST contain variable names and non-secret defaults only; domain models MUST contain zero payment or sensitive PII fields. | T1.4, T3.3, T3.11 |
| NFR2 | **Hexagonal Boundary (`INV-02`)**: `commerce_ai.config` and `commerce_ai.domain` MUST NOT import adapter or vendor libraries (`httpx`, `redis`, `serper`, `langfuse`, `boto3`). | T1.11, T5.4 |
| NFR3 | **100% Offline Deterministic Verification (`INV-07`)**: Unit tests MUST pass completely offline with zero API keys or network calls within the `< 30 s` Phase 1 CI budget. | T4.1, T5.1 |
| NFR4 | **Code Quality & Strict Typing**: All code and tests MUST pass `ruff check .`, `ruff format --check .`, and `mypy src` with zero warnings or errors. | T5.2, T5.3, T5.4 |

## 3. Constraints
- **C1**: Must uphold `spec/tech.md` invariants `INV-01`, `INV-02`, `INV-03`, `INV-05`, `INV-07`, and `INV-09`.
- **C2 (`P7`)**: Must NOT create `domain/ranking.py`, `domain/ports.py`, `adapters/catalog/*` modules beyond `__init__.py`, or `adapters/cache/*` modules beyond `__init__.py`; Features 1.2 and 1.3 own those files and must not modify `backend/pyproject.toml` or any `__init__.py` created here.
- **C3**: Must preserve exact Phase 1 contract spellings, enum values, field types/defaults, and method signatures (`CountryCode`, `CurrencyCode`, `StoreId`, `StoreFilter`, `CatalogSourceMode`, `ProductOffer`, `SearchIntent`, `RankedOffer`, `RankingResult`, `CatalogSearchResult`, `ScoringConfig`, `MarketConfig`, `MARKET_REGISTRY`, `AppSettings`, `DomainError`, `OfferValidationError`, `CatalogProviderError`, `CacheStoreError`).
- **C4**: Must never commit `.env` or secret values to git (`INV-01`).

## 4. Dependencies & Assumptions
- **Depends on**: None (root foundation of Phase 1). Downstream consumers: Feature 1.2 (`domain/ranking.py`) and Feature 1.3 (`domain/ports.py`, `adapters/catalog/`, `adapters/cache/`).
- **Environment variables (names only)**: `SERPER_API_KEY`, `REDIS_URL`, `CATALOG_MODE`, `CACHE_TTL_SECONDS`, `SERPER_TIMEOUT_SECONDS`.
- **Assumptions**:
  - `uv` (`>= 0.13`) and Python `3.11+` are available in the development environment (verified `uv 0.13.1` and `cpython 3.11.17`).
  - Package dependencies can be resolved once via `uv sync --directory backend --all-extras --dev` during Feature 1.1 setup; subsequent test runs remain 100% offline.
  - Root `.gitignore` already excludes `.env`, `.env.*`, `!.env.example`, `__pycache__/`, `*.py[cod]`, `.venv/`, `*.db`, `node_modules/`, and `.next/`, and will be augmented with `.pytest_cache/`, `.ruff_cache/`, `.mypy_cache/`, and `*.egg-info/` under `# Python`; existing `backend/.env.example` and `frontend/.env.example` are preserved verbatim.
